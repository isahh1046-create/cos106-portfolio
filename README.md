# COS 106 Portfolio & Academic Management Website

Student: Harun Isah — MIVA Open University (B.Sc. Cyber Security)

## Pages
| File | Description |
|------|-------------|
| index.html | Homepage: photo, welcome message, biography, multimedia |
| about.html | Education background, career aspirations, skills, hobbies |
| projects.html | Three cyber security projects: Password Strength Checker, Caesar Cipher Tool, Phishing Awareness Quiz |
| planner.html | Interactive academic planner (add / complete / delete tasks) |
| contact.html | Contact form with JavaScript validation |

## Features
- Semantic HTML5, external CSS, vanilla JavaScript
- Responsive layout (Flexbox + CSS Grid), mobile hamburger menu
- Animations: scroll reveal, floating avatar, hover transitions, animated skill bars
- Planner persists tasks in localStorage
- Contact form validates: empty fields, email format, digits-only phone

## How to host on GitHub Pages (free)
1. Create a GitHub account at https://github.com and create a new **public repository**, e.g. `cos106-portfolio`.
2. Upload all files/folders from this project into the repository (Add file → Upload files).
3. Go to **Settings → Pages**, set Source to `main` branch, `/ (root)`, and Save.
4. After ~1 minute your site is live at: `https://<your-username>.github.io/cos106-portfolio/`
5. Submit that link plus the repository link.

## Customisation
- Replace the avatar div in `index.html` with your photo (`<img src="images/photo.jpg" ...>`).
- Update the placeholder email, phone and GitHub links in `contact.html`.
- Update project links in `projects.html` with your real repo/demo URLs.
